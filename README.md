# 🛍️ Trendify - MERN E-Commerce Platform

Trendify is a full-stack e-commerce application built with the MERN stack, featuring secure authentication, product management, shopping cart, wishlist, order management, and Stripe payment integration.

---

## 🚀 Live Demo

**Frontend:**  
https://trendify-online.vercel.app

**Backend API:**  
https://e-commerce-3h1k.onrender.com

**API Documentation:**  
https://e-commerce-3h1k.onrender.com/api-docs

---

## ✨ Features

- 🔐 JWT Authentication (HTTP-only Cookies)
- 🛍️ Product Browsing & Search
- ❤️ Wishlist Management
- 🛒 Shopping Cart
- 📍 Address Management
- 💳 Stripe Payment Integration
- 📦 Order Management
- 👤 User Profile
- 📱 Fully Responsive Design

---

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- React Router
- Context API
- Axios
- Framer Motion
- Stripe

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Cookie Parser
- Swagger
